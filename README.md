# Wellness Chatbot

A Python-based wellness chatbot developed as part of my **Programming with Data** coursework.

## Overview

The Wellness Chatbot is an interactive chatbot designed to provide users with general wellness and emotional support through conversational interactions.

The project was developed using Python and a Jupyter Notebook, applying programming and data-handling concepts learned throughout the module.

## Features

* Interactive text-based chatbot
* Processes user input and generates appropriate responses
* Provides general wellness and emotional support
* Conversational interaction through a Python-based implementation

## Technologies Used

* Python
* Jupyter Notebook
* Python data-processing techniques

## How to Run

Clone the repository:

```bash
git clone https://github.com/lakshaya003/Wellness_Chatbot.git
```

Navigate to the project:

```bash
cd Wellness_Chatbot
```

Open the Jupyter Notebook:

```bash
jupyter notebook Chatbot.ipynb
```

Alternatively, open `Chatbot.ipynb` using JupyterLab or another compatible notebook environment and run the cells.
